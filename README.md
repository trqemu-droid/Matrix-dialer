# Matrix Dialer - Android Native Kotlin Source Code
**Developed by: TAREQUL ISLAM (Jr. officer, KDS Logistics Ltd. - Email: trqemu@gmail.com)**

Matrix Dialer is a full-featured Google Dialer alternative built in **Kotlin + Jetpack Compose**, featuring:
- **4-Way Calling Hub**: Direct one-touch buttons for SIM 1, SIM 2, WhatsApp Call, and Telegram Call.
- **Eyecon Caller Intelligence**: Social profile extraction (Facebook ID, WhatsApp, LinkedIn, spam scoring).
- **Call Audio Recorder Engine**: Toggleable in-call audio recording using `MediaRecorder`.
- **DTMF Audio Synthesizer**: Dual-tone telephone keypad audio using `ToneGenerator`.
- **Material 3 Dynamic Theming**: Dark & Light mode switch.
